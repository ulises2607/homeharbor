# Backend de Homeharbor

API Rails y PostgreSQL. Ejecutar todos los comandos Rails desde esta carpeta.

Las instrucciones vigentes de instalación, variables, correo local, pruebas y herramientas portables están en el [README de la raíz](../README.md). El [contrato](../docs/API_V1.md) distingue endpoints implementados de entregables pendientes.

Las rutas HTML históricas de Devise y Google no están expuestas. La identidad de las operaciones procede de la sesión Rails. El dominio de reservas se implementará en E4.
